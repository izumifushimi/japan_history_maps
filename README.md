# 日本历史图谱

一个从绳文时代延伸至当代日本的中文交互式历史地图。地图按照所选年份展示政权、势力范围、政治中心、当年首脑、重大事件及可得的年度人口与经济数据。

## 主要内容

- 可逐年拖动的历史时间轴
- 日本各时期政权与分裂势力的颜色区分
- 都道府县与市区町村边界
- 琉球群岛、北海道、北方四岛及近代海外统治与军事占领区域
- 天皇、幕府将军与内阁总理大臣的同时展示
- 战后经济复苏、高速增长、泡沫经济及当代阶段
- 可得年份的全国人口、名义 GDP 与产业增加值排序

## 本地运行

项目是静态网站。为避免浏览器阻止本地数据加载，请在仓库根目录启动 HTTP 服务：

```bash
python3 -m http.server 4173 --directory dist
```

随后访问 <http://localhost:4173/>。

## GitHub Pages

仓库内的 `.github/workflows/pages.yml` 会在 `main` 分支更新后，将 `dist/` 自动部署到 GitHub Pages。

首次使用时，请在 GitHub 仓库的 **Settings → Pages → Build and deployment** 中将 Source 设为 **GitHub Actions**。

## 数据与外部资源

本仓库包含网站主体、现代年度数据和日本市区町村边界文件。页面运行时还会联网加载 Leaflet、世界及日本边界数据和 Wikimedia Commons 人物画像；相关来源与许可信息在页面署名及数据来源中标示。

历史疆域尤其是古代、战国及战时控制区域属于概略复原，不能替代专业历史地图或地方档案。
